# Documentation

This directory contains the technical documentation for the platform. `README.md`
at the repository root covers setup and day-to-day development; everything here
covers *how the system works* and *why it's built this way*.

Pages describe the system's intended design as features land milestone by
milestone — each page is updated as its corresponding module is
implemented, rather than written after the fact.
